Markets Research Terminal

No one tool had everything I wanted to see, so I built a single place to view it all. The dashboards below cover a few of the areas I'm tracking right now: macro and rates, housing, gold, and credit and debt across companies, households and the US government. The snapshot refreshes daily.

Dashboards

About this project

Purpose

Market data is spread across dozens of sources, and these dashboards put the series I follow side by side. The set changes as my focus does. Right now it covers the rates and macro backdrop, housing from the national level down to San Francisco ZIP codes, gold supply and demand, and credit conditions for companies, households and the federal government.

Method

Each dashboard is a Python module that fetches and caches its sources, runs the calculations (index rebasing, rolling betas, yield and multiple math, concentration indices, supply/demand balances), and returns Plotly figures, tables or written reads through FastAPI. The same backend originally powered these dashboards inside OpenBB Workspace. A build script snapshots every tile into this static site, checks each one for errors and keeps the last good version if a source fails.

Data and freshness

All data is public: FRED, the Federal Reserve, the New York Fed, the U.S. Treasury, the CFTC, Zillow, Redfin, the World Gold Council, LBMA and others, credited on each dashboard. A few tiles use tables transcribed from S&P Global Ratings' annual default study; they are marked as curated and updated yearly. The snapshot rebuilds daily. Each series updates on its own source's schedule, so monthly and quarterly data will lag the snapshot date. A tile marked stale means its latest refresh failed and it is showing the previous good snapshot.

Data comes from the public sources credited on each dashboard and remains subject to those providers' terms. Shown for research and educational purposes only. Nothing here is investment advice.
